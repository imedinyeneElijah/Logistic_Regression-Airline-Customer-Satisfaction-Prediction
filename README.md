# Logistic_Regression-Airline-Customer-Satisfaction-Prediction
The project demonstrates how machine learning can help airlines identify key drivers of customer satisfaction and support data-driven business decisions aimed at improving customer experience and retention.


## Project Objective
Predict whether an airline passenger is satisfied or dissatisfied using Logistic Regression.

## Dataset
Invistico Airline Dataset

## Tools Used
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Scikit-Learn

## Methodology
1. Data Cleaning
2. Missing Value Treatment
3. Feature Encoding
4. Feature Scaling
5. Train-Test Split
6. Logistic Regression
7. Model Evaluation

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- Confusion Matrix
- ROC-AUC

## Key Business Insights
- Online boarding strongly influences satisfaction.
- Inflight Wi-Fi quality significantly impacts customer experience.
- Seat comfort contributes to passenger retention.
- Flight delays negatively affect satisfaction.

## Business Recommendations
- Improve Wi-Fi service.
- Reduce delays.
- Enhance online support.
- Improve seat comfort.
- Focus on customer experience programs.
